# Town character atlas

Generated with the built-in imagegen tool for Fairy World. `characters.png` contains 28 portraits in a four-column, seven-row grid. Display with CSS background-size 400% 700%; portraits are square.

Prompt specification: grounded, painterly medieval fantasy NPC bust portraits, dark teal backgrounds and muted gold light; expressive, distinct faces, worn leather and rich cloth; no text or watermark. Exact 4 × 7 equal-cell grid. Columns: merchant, blacksmith, auctioneer, quest giver. Rows: Aurelia (sunlit human capital), Moonfall (silver-haired lunar elves), Evercross (weathered caravan travelers), Mosskeep (green woodland folk), Westmere (navy and amber harbor folk), Frostwatch (fur-clad northern folk), Larkhaven (emerald and copper artisans). Each town has four different people, with age and appearance varied by role.

Names, greetings and cell coordinates live in src/modules/Towns/characters.ts. These are illustrated portraits, not skeletal character animations.
